# 로그 다듬기 · 채팅방 전체 백업 · EPUB 제작

로판Ai 로그와 일반 로그를 정리하고, 검토 후 TXT/HTML/Markdown/DOC용 HTML/EPUB으로 내보내는 단일 페이지 웹앱입니다.

## 주요 기능

- `로그 다듬기` 탭: `*지문*`과 일반 대사를 분리해 정리
- `채팅방 전체 백업` 탭: 로판Ai 전체 채팅방 복붙 또는 `.mht/.mhtml/.html` 파일 업로드 지원
- 기울임체는 지문, 일반 문단은 대사로 처리
- 접힘 토큰, 빈 줄, HTML 태그, 구분선/기호 줄 정리
- 특정 글자 포함 문단 삭제 또는 확인 후 선택
- 영어 키워드 대소문자 무시 처리
- 블록/표 제거
- 중복 답변 후보를 한 후보씩 넘겨 보며 선택
- 채팅방 백업 탭 전용 이름표 출력
- 결과 통계, 위험 문구 감지, 검토 선택 초기화
- 옵션 프리셋 저장/불러오기
- EPUB 메타데이터, 표지, 챕터 분리, 스타일 프리셋, 본문 미리보기
- TXT, HTML, Markdown, DOC용 HTML, EPUB 다운로드

## 사용 팁

채팅방 전체 백업 탭에서는 Chrome에서 페이지를 `.mht`로 저장한 뒤 업로드할 수 있습니다. 일반 텍스트는 기울임체 정보가 사라질 수 있습니다.

EPUB 제작 섹션의 `EPUB에서는 제거` 또는 `소설화 모드`를 사용하면 작업용 이름표를 결과 검토에는 활용하고 EPUB 원고에서는 제거할 수 있습니다.
