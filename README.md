# AI 로그 다듬기

단일 `index.html`로 실행되는 로판Ai용 로그 다듬기 웹앱입니다.

## 주요 기능

- 기존 로그 다듬기: `*지문*`은 지문, 나머지는 대사로 처리합니다.
- 로판Ai 전체 채팅방: 서식 있는 채팅방 내용을 그대로 붙여넣으면 기울임체는 지문, 기울임이 아닌 부분은 대사로 처리합니다.
- 로판Ai 저장 파일 불러오기: 브라우저에서 저장한 `.mht`, `.mhtml`, `.html`, `.htm` 파일을 불러와 채팅 내용을 추출합니다.
- 잘못 올린 ZIP/DOCX 같은 압축 파일은 변환기에 깨진 글자로 넣지 않고 안내 메시지로 막습니다.
- 원본 붙여넣기 칸은 긴 문장, 넓은 블록, 큰 HTML 요소가 들어와도 옆으로 밀리지 않도록 고정 폭으로 표시합니다.
- 옵션 UI를 버튼형 토글과 기능별 카드 묶음으로 정리했습니다.
- 공통 출력 옵션: 접힘 토큰 제거, 빈 줄 제거, HTML 태그 제거, 구분선/기호 줄 제거, 보호 키워드, 따옴표 스타일, 결과 복사, TXT 다운로드.
- 로판Ai 탭 추가 옵션: 특정 글자 포함 문단 삭제, 블록/표/기록지 카드 제거, 이름표 붙이기, 중복 답변 확인 후 선택.

## 이번 수정 사항

- 로판Ai 채팅방 맨 처음에 있는 캐릭터 인트로/첫 답변이 첫 유저 지문 위에 있어도 삭제되거나 유저 문단으로 잘못 묶이지 않도록 보정했습니다.
- `p` 태그를 무조건 유저 문단으로 처리하지 않고, 글자색 단서가 있으면 색상 기준을 먼저 적용합니다.
- 이름표가 지문 내부의 모든 줄마다 반복되지 않고, 하나의 입력/답변 블록이 시작될 때만 붙습니다.
- 입력칸과 결과칸의 가로 넘침을 더 강하게 막고, 옵션 영역의 카드/토글 디자인을 정리했습니다.

## 로판Ai 탭 세부 옵션

- `이름으로 구분`: 내 캐릭터/유저 이름과 플레이 캐릭터 이름을 입력하면, 로판Ai의 입력 구간과 답변 구간 또는 글자색 단서를 이용해 문단 앞에 이름표를 붙입니다.
- 이름표는 `이름만`, `▪︎ 이름`, `• 이름`, `◆ 이름`, 직접 입력 중에서 고를 수 있습니다.
- 이름표 색상은 적용하지 않거나, 유니코드 기호만 또는 이름표 전체에 적용할 수 있습니다. 색상 적용 시 결과에는 `<span style="color:#...">` 형식의 HTML이 들어갑니다.
- `중복 답변 확인 후 선택`: 같은 유저 입력에 여러 답변 후보가 붙어 있거나 같은 답변이 반복된 경우, 후보를 블록으로 보여주고 하나만 남길 수 있습니다. 기본값은 모두 유지입니다.
- `특정 글자 포함 문단 삭제` + `확인 후 선택`: 키워드가 들어간 문단을 각각 블록으로 보여주고 남김/삭제를 고를 수 있습니다. 기본값은 남김입니다.

## 사용법

`index.html`을 브라우저에서 열어 사용합니다.

로판Ai 전체 채팅방 탭에서는 두 가지 방식으로 입력할 수 있습니다.

1. 브라우저 채팅방에서 바로 복사해 붙여넣기
2. 브라우저에서 페이지를 MHT/MHTML/HTML로 저장한 뒤 `로판Ai 저장 파일 불러오기`로 업로드

메모장처럼 서식 없는 곳을 거치면 기울임 정보를 읽을 수 없습니다.
