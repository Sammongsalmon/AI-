# 로그 다듬기 · 채팅방 전체 백업 · EPUB 수정

로판Ai 로그와 일반 로그를 정리하고 TXT/HTML/Markdown/DOC용 HTML/EPUB으로 내보내는 단일 페이지 웹앱입니다.

## 이번 수정

앱(안드로이드) 쪽에서 쓰는 발췌기와 같은 판으로 맞췄습니다.

- `OOC 응답 검토`에 **남김**을 더했습니다. 예전에는 'OOC 문단만 삭제 · 전체 유저 지문
  삭제 · 응답까지 삭제' 셋뿐이라, 검토 목록에 오른 OOC 는 어느 것을 골라도 지워졌습니다.
  한꺼번에 고르는 자리에도 `전체 남김`이 있습니다.
- 따옴표를 붙이지 않을 줄을 고를 수 있습니다.
  - `따옴표 제외`: 없음 / 이모지만 있는 줄 / 이모지 섞인 줄
  - `HTML 태그 빼고`: `<br>` 같은 태그뿐인 줄은 빼고, 대사에 감긴 태그는 따옴표를
    글자 쪽으로 들여보냅니다 (`<b>안녕</b>` → `<b>"안녕"</b>`)
  - `기호 섞인 줄 빼고`: `※ 안내` · `【상태창】 체력` 처럼 기호를 달아 둔 줄에는
    붙이지 않습니다. 글자와 흔한 문장부호는 기호로 치지 않으므로 보통 대사는 그대로입니다.
- 불러온 발췌 파일에 이름이 있으면, 따로 지정하지 않는 한 그 이름으로 내보냅니다.
- 위 선택지는 모두 프리셋에 실립니다. 기본값은 전부 꺼짐 — 예전 동작 그대로입니다.

## 주요 기능

- `로그 다듬기`: 별표 지문과 대사를 정리합니다.
- `채팅방 전체 백업`: MHT/MHTML/HTML/Markdown/TXT 백업을 읽어 지문과 대사를 구분합니다.
- `EPUB 수정`: TXT/Markdown/HTML/EPUB 파일을 불러와 본문을 수정하고 다시 저장합니다.
- 중복 답변 검토, OOC 응답 검토, 키워드 삭제 검토, 블록/표 제거, 이름표 설정을 지원합니다.
- 앱에서 내려받은 HTML/Markdown은 유저·캐릭터, 지문·대사 구조 정보를 보존합니다.

## 참고

작업 내용과 설정은 브라우저 로컬 저장소에 자동 저장됩니다. 같은 기기와 같은 브라우저 프로필에서만 복원됩니다.

## 이번 수정

- 챕터 끝 지점 설정 시 현재 편집 중인 챕터만 변경되도록 보강했습니다.
- 뒤 챕터를 설정해도 앞 챕터의 끝 지점은 보존됩니다.
- 마지막 챕터의 끝 지점이 글 끝보다 앞이면 다음 챕터가 자동으로 추가됩니다.
- 챕터 미리보기 항목을 누르면 펼쳐지도록 다시 보강했습니다.
- 로그 다듬기/채팅방 전체 백업 탭의 정리 옵션과 검토 보드는 기본 펼침 상태로 시작합니다.

## 이번 수정

- 챕터 단위 계산을 다시 정리했습니다.
  - TXT 원고는 줄바꿈 단위로 챕터 끝 지점을 계산합니다.
  - 앱에서 내려받은 Markdown/HTML처럼 구조 정보가 있는 원고는 유저/캐릭터 응답 셀 단위로 계산합니다.
- 챕터 미리보기에서 대사와 지문 줄바꿈이 붙어 보이지 않도록 본문 HTML을 다시 구성했습니다.
- 챕터 미리보기 카드의 제목, 범위, 글자 수, 본문 표시를 더 읽기 좋게 다듬었습니다.

## 이번 수정

- 챕터 추가 버튼은 항상 현재 챕터 목록의 맨 뒤에 새 챕터를 추가합니다.
- 챕터 편집은 클릭한 챕터 ID를 기준으로 열리며, 마지막 챕터를 편집해도 첫 챕터 편집창으로 돌아가지 않도록 보강했습니다.
- 챕터명/문구/이미지 위치 수정은 챕터 끝 지점 값을 다시 계산하지 않고 해당 필드만 저장합니다.
- 챕터 끝 지점 설정은 현재 편집 중인 챕터만 변경하며, 앞 챕터의 끝 지점은 건드리지 않습니다.
- 챕터 설정 초기화 버튼을 추가했고, 저장 캐시 삭제 시 챕터 설정도 함께 삭제됩니다.
