# AI 로그 다듬기

단일 `index.html`로 실행되는 로판Ai용 로그 다듬기 웹앱입니다.

## 주요 기능

- 기존 로그 다듬기: `*지문*`은 지문, 나머지는 대사로 처리합니다.
- 로판Ai 전체 채팅방: 서식 있는 채팅방 내용을 그대로 붙여넣으면 기울임체 문단은 지문, 기울임이 아닌 문단은 대사로 처리합니다.
- 공통 출력 옵션: 접힘 토큰 제거, 빈 줄 제거, HTML 태그 제거, 구분선/기호 줄 제거, 보호 키워드, 따옴표 스타일, 결과 복사, TXT 다운로드.
- 로판Ai 탭 추가 옵션: 특정 글자 포함 문단 삭제, 블록/표 제거.

## 사용법

`index.html`을 브라우저에서 열어 사용합니다. 로판Ai 전체 채팅방 탭은 서식을 읽어야 하므로 메모장 같은 일반 텍스트 편집기를 거치지 말고 브라우저 채팅방에서 바로 복사해 붙여넣는 것을 권장합니다.
