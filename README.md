# 로그 다듬기 · 채팅방 전체 백업 · EPUB 수정

로판Ai 로그와 일반 로그를 정리하고 TXT, HTML, Markdown, DOC용 HTML, EPUB으로 내보내는 단일 페이지 웹앱입니다.

## 이번 안정화 내용

- `로그 다듬기`, `채팅방 전체 백업`, `EPUB 수정` 탭의 파일 불러오기 흐름을 다시 연결했습니다.
- 파일 선택 버튼은 실제 파일 input이 버튼 전체를 덮는 방식으로 바꿔 모바일/데스크톱에서 클릭 누락이 줄어들도록 했습니다.
- 변환 중 오류가 나도 결과창이 빈칸으로 멈추지 않도록 fallback 변환 흐름을 추가했습니다.
- 로그 다듬기 입력창도 앱이 만든 HTML/Markdown 코드의 색상, 이름표, 챕터 구분선을 렌더링해서 보여줍니다.
- Markdown 구조 주석 앞에 있는 첫 문단도 버리지 않고 `character / scene` 기본값으로 읽습니다.
- 챕터 구분선은 보이는 문자열만으로 판단하지 않고 내부 챕터 마커와 `<hr>`를 기준으로 분리합니다.
- 구분선/기호 줄 제거 옵션과 챕터 분리 계산이 서로 충돌하지 않도록 분리했습니다.
- EPUB 제작 목차와 미리보기는 현재 탭의 텍스트를 기준으로 갱신됩니다.

## 참고

TXT는 유저/캐릭터/지문/대사 정보를 구조적으로 보존하지 않습니다. 앱에서 내려받은 Markdown/HTML은 `data-owner`, `data-kind`, `rofan` 주석을 포함해 다시 불러올 때 구조를 최대한 복원합니다.
