# AI 로그 다듬기

단일 `index.html`로 실행되는 로판Ai용 로그 다듬기 웹앱입니다.

## 주요 기능

- `로그 다듬기`: `*지문*`은 지문, 나머지는 대사로 처리합니다.
- `채팅방 전체 백업`: 서식 있는 로판Ai 채팅방 내용을 붙여넣거나, Chrome에서 페이지 다운로드로 받은 `.mht/.mhtml/.html` 파일을 업로드해 전체 내용을 한 번에 변환합니다.
- 공통 옵션: 접힘 토큰 제거, 빈 줄 정리, HTML 태그 제거, 구분선/기호 줄 제거, 보호 키워드, 따옴표 스타일, 특정 글자 포함 문단 삭제, 블록/표 제거, 이름표 붙이기.
- 로판Ai 검토 옵션: 중복 답변 확인 후 선택, 특정 글자 포함 문단 확인 후 선택.
- 원본 붙여넣기 칸은 긴 문장과 넓은 HTML 요소가 들어와도 가로로 밀리지 않게 고정됩니다.

## 이번 수정 사항

- 탭 이름을 `로그 다듬기`, `채팅방 전체 백업`으로 변경했습니다.
- `기본 정리`, `출력 형식` 등 옵션 블록 제목 앞의 숫자를 제거했습니다.
- 로판Ai 검토/이름표 옵션을 두 탭에서 모두 보이도록 했습니다.
- 이름 입력칸의 예시 placeholder를 제거했습니다.
- 채팅방 전체 백업 탭에 “Chrome에서 페이지 다운로드 옵션으로 .mht 파일을 받아 업로드하면 전체 내용을 한 번에 붙여넣을 수 있습니다.” 안내를 추가했습니다.
- 중복 답변 후보는 한 묶음 안에서 후보 하나씩 넘겨 보며 선택할 수 있게 했습니다.
- 중복 답변 검토 기준을 보강해, 유저 지문이 조금 달라도 두 문장 이상 겹치면 같은 질문 후보로 묶습니다.
- 중복 묶음의 대표 입력은 가장 자주 나온 지문으로 보여주고, 최종 반영 시에는 선택한 답변에 연결된 유저 지문을 남깁니다.
- 특정 글자 포함 문단 삭제 키워드는 영어 알파벳 대소문자를 구분하지 않습니다. 예: `ooc` 하나만 입력해도 `OOC`, `Ooc`, `ooc`를 모두 잡습니다.
- 검토 패널은 변환 입력/출력 창 아래에 표시됩니다.

## 사용법

`index.html`을 브라우저에서 열어 사용합니다.

채팅방 전체 백업 탭에서는 두 가지 방식으로 입력할 수 있습니다.

1. 브라우저 채팅방에서 바로 복사해 붙여넣기
2. Chrome에서 페이지 다운로드 옵션으로 `.mht/.mhtml/.html` 파일을 저장한 뒤 업로드

메모장처럼 서식 없는 곳을 거치면 기울임 정보를 읽을 수 없습니다.

- 중복 후보 검토 문단은 말줄임 없이 전체 내용을 표시합니다.
