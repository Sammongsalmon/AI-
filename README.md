# 로그 다듬기 · 채팅방 전체 백업 · EPUB 수정

로판Ai 로그와 일반 로그를 정리하고 TXT/HTML/Markdown/DOC용 HTML/EPUB으로 내보내는 단일 페이지 웹앱입니다.

## 주요 기능

- `로그 다듬기`: 별표 지문과 대사를 정리합니다.
- `채팅방 전체 백업`: MHT/MHTML/HTML/Markdown/TXT 백업을 읽어 지문과 대사를 구분합니다.
- `EPUB 수정`: TXT/Markdown/HTML/EPUB 파일을 불러와 본문을 수정하고 다시 저장합니다.
- 중복 답변 검토, OOC 응답 검토, 키워드 삭제 검토, 이모지 포함 문단 제거, 블록/표 제거, 이름표 설정을 지원합니다.
- 앱에서 내려받은 HTML/Markdown은 유저·캐릭터, 지문·대사 구조 정보를 보존합니다.
- 챕터는 수동 목차 방식으로 관리하며, 챕터명/끝 지점/소제목 문구/이미지를 설정할 수 있습니다.

## 이번 정리

- 예전 구분선 삽입 기능에서 남은 챕터 구분선 마커를 본문/미리보기/내보내기에서 제거하도록 정리했습니다.
- EPUB 수정창에서는 현재 챕터 설정 기준의 시각적 구분선만 챕터 사이에 하나씩 다시 그리도록 보강했습니다.
- 기존 레이아웃과 동작은 유지하면서 배포용 문법 검사를 통과했습니다.
