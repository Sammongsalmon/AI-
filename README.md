# 로그 다듬기 · 채팅방 전체 백업 · EPUB 수정

로판Ai 로그와 일반 로그를 정리하고, TXT/HTML/Markdown/DOC용 HTML/EPUB으로 내보내는 단일 페이지 웹앱입니다.

## 주요 기능

- `로그 다듬기` 탭: `*지문*`과 일반 대사를 분리해 정리
- `로그 다듬기` 탭 파일 발췌: MHT/HTML/TXT/Markdown 파일을 올리고 시작/끝 문장으로 필요한 범위만 추출
- `채팅방 전체 백업` 탭: 로판Ai 전체 채팅방 복붙 또는 `.mht/.mhtml/.html` 업로드 지원
- `EPUB 수정` 탭: TXT/Markdown/HTML/EPUB 파일을 불러와 본문을 편집하고 EPUB으로 다시 저장
- 찾기/바꾸기, 선택 문장 인용구, 선택/전체 글자 크기·색상, 폰트 업로드 지원
- 접힘 토큰, 빈 줄, HTML 태그, 구분선/기호 줄 정리
- 키워드 삭제 검토, OOC 응답 검토, 중복 답변 검토
- 서식 설정: 채팅방 백업 이름표와 EPUB용 출력 설정
- EPUB 메타데이터, 표지, 챕터 분리, 스타일 프리셋, 본문 미리보기
- 자동 저장, 프리셋, 작업 캐시 복원

## 참고

TXT는 유저/캐릭터/지문/대사 정보를 구조적으로 보존하지 않습니다. Markdown/HTML은 클래스나 데이터 속성을 넣어 저장하면 보존할 수 있지만, 일반 Markdown/HTML로 저장하면 대부분 텍스트 형태로만 복원됩니다. 그래서 앱 안에서는 가능한 범위에서 서식 설정과 EPUB 수정 도구로 다시 일괄 조정할 수 있게 구성했습니다.
